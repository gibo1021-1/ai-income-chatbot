# 검증 결과

검증일: 2026-11-02 (한국 시간). 공개 배포 없이 로컬 프로덕션 서버와 시스템 Chromium을 사용했습니다.

## 확인한 사용자 흐름

무료 시작 화면 → 버튼형 네 질문 → 브라우저 메모리의 답변 → 점수 계산 → 세 유형별 강의 추천 → 외부 링크 안내.

API·DB·유료 AI 호출은 없으며 입력 답변을 서버로 전송하지 않습니다.

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| 프로덕션 빌드 | 통과 | `npm run build`: 정적 페이지 생성 완료 |

## 실제 주소가 필요한 항목

무료 자료·상담·결제 URL은 제공되지 않았습니다. 미설정 항목을 준비 중으로 표시하는 것을 확인했습니다. 실제 외부 서비스의 자료 다운로드, 상담 접수, 결제 완료는 검증하지 않았습니다. `.env.example`의 다섯 주소를 입력하고 재빌드하면 연결됩니다.

## 배포와 보존

- 공개 배포 명령을 실행하지 않았습니다.
- GitHub Pages 배포 워크플로를 추가하지 않았습니다.
- Vercel의 Git 기반 자동 배포를 `vercel.json`에서 비활성화했습니다.
- 원본 저장소와 별도 `feat/ai-income-diagnosis` 브랜치를 사용합니다.
- `README.md`에 clone·설치·실행 및 원격 커밋 확인 절차가 있습니다.
